GORDON · CONTENT EDITOR

內容編輯器

不必碰 HTML 程式碼，也能修改網站介紹與文章。完成後下載新版內容檔案，再上傳到 GitHub。

本頁只會在你的瀏覽器裡操作資料，不會自動儲存到網路，也不會修改 GitHub。建議每次編輯前先備份原始網站。

02 · JOURNAL

編輯文章

直接貼上完整繁體中文文章即可。編輯器會依空白行分成段落，不會擅自修改文字。

發布步驟：按「下載新版 site-content.js」後，到 GitHub 儲存庫的 site-content.js，選擇上傳檔案取代舊檔，再提交變更。如果你改了封面圖片路徑，記得先把圖片上傳到 assets 資料夾。此頁不會自動發布，方便你先審閱。
