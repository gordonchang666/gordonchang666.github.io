一、最方便的上傳方式
1. 解壓縮本 ZIP 檔。
2. 在 GitHub 儲存庫 main 分支根目錄找到既有的 site-content.js。
3. 如果 GitHub 上的 site-content.js 自製作本套件以來沒有其他更新，
   可於上傳頁將本資料夾根目錄的 site-content.js 拖入，取代同名檔案，提交 Commit changes。
4. 文章的 slug 為 you-gotta-win-it，將在「知微創作」分類中出現。
5. 網站發佈完成後，可開啟上方文章網址查看。

二、如果 GitHub 上的 site-content.js 已有其他更新
請勿直接拿這份完整 site-content.js 覆蓋目前網站，以免刪除期間的新內容。
應打開安全更新用/新增文章片段_貼入posts清單.txt，將該 JavaScript 物件
加入目前最新版 site-content.js 的 posts: [ ... ] 內（注意相鄰逗號）；
建議放在 2026.11.24 與 2026.11.17 文章之間。
也可利用安全更新用/文章資料.json 取得格式化後的所有欄位。

三、套件內容
- site-content.js：以當時已核對的 GitHub 最新版本為底，安全新增此篇後的完整網站資料檔
- 安全更新用/文章資料.json：單篇資料，UTF-8
- 安全更新用/新增文章片段_貼入posts清單.txt：不覆蓋原有資料的貼入片段
- 文章原稿與預覽/You gotta win it.html：可離線閱讀、列印的單篇 HTML 預覽
- 文章原稿與預覽/You gotta win it.md：Markdown 原稿
- 文章原稿與預覽/You gotta win it.txt：純文字原稿
