# 章竣 Gordon｜個人網站（免費架站初版）

這是一份可以直接放到 **GitHub Pages** 發布的繁體中文個人網站。它以 **章竣 Gordon** 為網站主體，包含自我介紹、電影心得、知微創作、生活紀錄、專業方向與社群連結。

- **首頁**：主視覺、網站定位、簡短自我介紹、三大文章專區、專業方向與聯絡區。
- **部落格第一篇**：〈你好，我是章竣 Gordon〉。這是依已知經歷撰寫的**自我介紹草稿**，請你審閱後再公開。
- **電影心得專區第一篇**：〈我們曾真心相伴的時光〉。已完整放入你於 **2026 年 11 月 3 日** 審定發表的六段文字、標題、署名、日期與原始封面註記，沒有改寫正文。
- **知微創作／生活紀錄**：已建立分類與空白狀態，待你陸續放入正式作品。
- **響應式排版**：支援桌面、平板、手機；含手機導覽與文章閱讀版型。

## 如何自己預覽？

下載 ZIP 並解壓縮後，在電腦上雙擊 `index.html` 預覽網站；雙擊 `editor.html` 就能透過表單修改內容。這是靜態網站，無須安裝程式，也不用購買主機。

## 免費公開發布（GitHub Pages）

1. 到 https://github.com 註冊／登入 GitHub。
2. 建立新的 **Public** 儲存庫，名稱設為：`你的 GitHub 使用者名稱.github.io`（必須與實際使用者名稱相同）。你目前連接的 GitHub 使用者名稱是 `gordonchang666`，因此推薦儲存庫命名為 **`gordonchang666.github.io`**。
3. 在儲存庫的 **Add file → Upload files**，將這個資料夾裡的檔案**與 `assets` 資料夾**一起上傳。注意 `index.html` 必須放在儲存庫最上層，圖片則要保留 `assets/...` 路徑。你也可使用 GitHub Desktop 上傳整個資料夾。
4. 進入 **Settings → Pages**，Source 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/(root)`，儲存。
5. 若使用上述帳號與儲存庫名稱，網站發布成功後的網址會是 **`https://gordonchang666.github.io/`**（**目前尚未發布，這不是已上線的網站**）。GitHub Pages 發布通常需要一點時間。
6. 將網站網址加入你的 Instagram 個人檔案「連結」即可。往後可以直接在 GitHub 網頁編輯檔案並提交變更。

官方說明：https://docs.github.com/en/pages/quickstart

> **安全提醒**：GitHub Free 的 Pages 一般使用公開儲存庫，原始碼、貼文與你加入的照片都會被公開。不要加入學號、住家地址、證件、非公開研究內容或未獲授權的他人照片。

## 未來怎麼修改？只要先認識 `site-content.js`

你可以先用 **`editor.html` 內容編輯器**，像填表單一樣修改自我介紹、IG、文章、日期與分類，完成後點「下載新版 site-content.js」，再上傳到 GitHub 取代舊檔。這種做法不需要懂 JavaScript，但仍需自行提交到 GitHub 才會公開更新。

進階用法：這份網站的文章與自我介紹集中在 `site-content.js`；也可直接修改這個檔案。上線後則在 GitHub 進入該檔案，按鉛筆編輯，最後按 **Commit changes**。

### A. 更新個人簡介

在 `site-content.js` 檔案頂端的 `site` 區塊，修改：

- `heroDescription`：首頁第一屏的簡介。
- `about`：「關於我」區塊的短介紹。
- `instagramUrl`：IG 完整網址，例 `https://www.instagram.com/你的帳號/`。
- `email`：願意公開的合作聯絡信箱；保留空字串 `''` 則不顯示。

### B. 修改第一篇自我介紹

在 `posts` 內找到 `slug: 'hello-im-gordon'`：

- `title` 是標題；`subtitle` 是副標；`date` 是文章日期。
- `paragraphs` 內每一組反引號（\`文字\`）就是一個段落。直接改字即可。
- 目前自我介紹是草稿，**這篇才是整個部落格的第一篇**。

### C. 電影專區的第一篇與封面

在 `posts` 找到 `slug: 'we-were-together'`，目前已放入全部正式正文。

麻吉照片：將照片取名 `maji.jpg`、放進 `assets/`，再把該篇文章的 `coverImage: ''` 改成：

```js
coverImage: 'assets/maji.jpg',
```

若你的照片是 PNG，請改用 `maji.png` 與相應路徑。上傳前請確定照片為你有權公開使用的原圖。

### D. 新增新的知微、電影或生活文章

在 `posts: [...]` 裡複製一篇完整的 `{ ... }` 物件，改寫標題、日期、內文與 `slug`（不可重複）。

分類填入：`film`（電影心得）、`zhiwei`（知微創作）、`life`（生活紀錄），或 `about`（自我介紹）。例如：

```js
{
  slug: 'my-new-note',
  category: 'zhiwei',
  title: '我的新文章',
  subtitle: '——一則生活感想',
  date: '2026.11.10',
  author: '章竣 Gordon',
  excerpt: '這篇文章的簡短摘要。',
  coverImage: '',
  coverCaption: '',
  paragraphs: [
    `文章第一段。`,
    `文章第二段。`
  ],
  footnote: ''
},
```

新文章可以放在 `posts` 陣列最前面；分類篩選與文章閱讀畫面會自動更新。當修改程式碼需要幫忙時，把 `site-content.js` 或整份 ZIP 傳回 ChatGPT 即可繼續調整。

### E. 修改排版、配色與字體

開啟 `styles.css`，最前面的 `:root { ... }` 是網站配色與字體設定：

- `--paper`：米白色背景。
- `--ink`：文字顏色。
- `--accent`：陶土色重點。
- `--deep`：深綠色品牌主色。
- `--serif`：文章標題／內文的繁體中文襯線字體。
- `--sans`：一般網站文字字體。

## 目前技術與限制

- 架構：HTML + CSS + 原生 JavaScript；**不用付費資料庫、編輯器或託管服務**。
- 使用 GitHub Pages 免費的 `github.io` 網址。未來若要擁有獨立 `.com` 或 `.tw` 網址，通常需要另行付費購買網域；目前不需要。
- 這個版本**附有 `editor.html` 簡易表單內容編輯器**，可以在本機修改文章並下載更新檔案；它不是伺服器後台，也不會直接同步 GitHub。視覺配色與版面仍透過 `styles.css` 修改。
- 文章採用單頁動態閱讀畫面，適合第一階段使用；若未來想強化每篇文章的 Google 搜尋曝光與獨立社群分享預覽，建議再升級成 Jekyll 等可產生獨立文章網址的版本。
- 電影心得原貼文的**舒曼〈夢幻曲〉配樂**沒有被嵌入網站，避免涉及錄音版權。未來可以加入合法的官方音樂服務連結。
